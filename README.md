# DFisio Landing Page

Landing page desenvolvida para a DFisio, clínica de estética,
saúde e bem-estar em Cravinhos - SP.

## Objetivo

Criar uma presença digital moderna e facilitar o contato
de potenciais clientes através do WhatsApp.

## Principais recursos

- Layout responsivo
- Catálogo de procedimentos
- Integração com WhatsApp
- Seção de Pilates
- Depoimentos
- Localização e contato
- SEO básico

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
