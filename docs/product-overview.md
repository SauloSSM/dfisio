# DFisio — Product Overview

## Visão

Criar uma plataforma web para apoiar a operação comercial e,
futuramente, operacional da clínica DFisio.

A solução deverá reduzir oportunidades comerciais perdidas,
diminuir a dependência da memória e acompanhamento manual da
proprietária e fornecer maior visibilidade sobre o funcionamento
da clínica.

## Problema principal

Atualmente diversos processos dependem de acompanhamento manual.

Potenciais clientes podem não receber novo contato após uma
tentativa de agendamento malsucedida, cancelamento ou ausência
de resposta.

Além disso, a proprietária concentra atividades relacionadas a:

- marketing;
- acompanhamento comercial;
- caixa;
- estoque;
- venda de produtos;
- supervisão de tarefas.

## Objetivo inicial

A primeira versão terá foco comercial.

A prioridade é garantir que:

1. todo potencial cliente seja registrado;
2. cada oportunidade tenha um estado claro;
3. leads que necessitam acompanhamento possuam uma próxima ação;
4. tarefas atrasadas permaneçam visíveis;
5. seja possível medir a conversão do atendimento.

## Usuários iniciais

### Secretária

Responsável principalmente por:

- registrar leads;
- responder contatos;
- atualizar status;
- registrar interações;
- realizar follow-ups;
- organizar remarcações.

### Proprietária

Responsável principalmente por:

- acompanhar indicadores;
- visualizar pendências;
- identificar oportunidades perdidas;
- acompanhar a operação comercial.

## Modelo de distribuição

A solução será uma aplicação web hospedada.

Não haverá dependência de instalação local.

A clínica poderá acessar o sistema utilizando:

- computador;
- celular;
- tablet.

Os dados deverão permanecer centralizados e independentes dos
dispositivos utilizados.

## Áreas da aplicação

### Área pública

Destinada aos potenciais clientes.

Inicialmente:

- apresentação da clínica;
- serviços;
- diferenciais;
- CTA;
- formulário de interesse.

### Área administrativa

Destinada à equipe da clínica.

Inicialmente:

- gestão de leads;
- follow-ups;
- remarcações;
- histórico de interações;
- dashboard comercial.

## Princípios

- simplicidade antes de complexidade;
- baixo custo operacional;
- foco em problemas reais da clínica;
- nenhuma oportunidade deve depender exclusivamente da memória;
- dados clínicos não farão parte da V1;
- automação deve apoiar o trabalho humano, não complicá-lo.
